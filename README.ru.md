Swift-пакет с анимацией для SwiftUI на iOS 17+ и macOS 14+: пружины на основе физики, затухание (decay) и отскоки, перетаскивание, сохраняющее скорость пальца, эффекты частиц, эффекты изменений и переходы. Он предназначен для разработчиков приложений, которым нужен эффект на одном экране без подключения целого фреймворка: всё здесь — view modifier, `Animation`, `Transition` или простой тип-значение, а у пакета нет зависимостей.

## Основные возможности

- **Физика, которую можно вызывать напрямую** — `DampedSpring` решает уравнение пружины в замкнутом виде (тесты сравнивают результат с численным интегрированием), `Decay` вычисляет, где остановится бросок, `GravityBounce` роняет значение и заставляет его отскакивать, а `.gravityBounce()` запускает это как анимацию SwiftUI.
- **Перетаскивание с сохранением импульса** — `.elasticDrag()` и `.snapDrag(_:offsets:selection:)` передают пружине скорость в момент отпускания, растягиваются за краями с сопротивлением, как резинка, и позволяют броску дойти до следующей позиции покоя.
- **Частицы в одном Canvas** — 8 пресетов, 5 сил и 7 форм (включая SF Symbols и emoji), которые рисует один `Canvas`; симуляция с seed даёт одинаковые кадры при одинаковом seed и никогда не держит больше 10 000 частиц.
- **Эффекты изменений и переходы** — shake, jump, spin, pulse, ping и shine, которые проигрываются при изменении значения, а также переходы iris, wipe, flip и pop на основе протокола `Transition` из iOS 17.
- **Учитывается «Уменьшение движения»** — когда эта настройка включена, частицы не рисуются, эффекты изменений не проигрываются, переходы заменяются плавным появлением, а перетаскивание завершается коротким ease-out.
- **Протестировано, Swift 6** — 63 теста Swift Testing на macOS и в симуляторе iPhone, включая NaN, бесконечные значения и значения вне диапазона; пакет собирается в языковом режиме Swift 6.

### Что входит в пакет

| Область | API |
| --- | --- |
| Физика | `DampedSpring` (`gentle`, `snappy`, `bouncy`, `smooth`), `Decay`, `GravityBounce`, `.gravityBounce(fallDuration:restitution:)`, `RubberBand`, `SnapPoints` |
| Жесты | `.elasticDrag(axes:resistance:spring:)`, `.snapDrag(_:offsets:selection:decay:spring:)` |
| Частицы | `.particleBurst(_:trigger:)`, `.particleEffect(_:isActive:)`, `ParticleView`, `ParticleEmitter`, `ParticleForce`, `ParticleSystem` |
| Пресеты | `confetti`, `fireworks`, `snow`, `rain`, `sparkles`, `bubbles`, `hearts`, `embers` |
| Эффекты изменений | `.changeEffect(_:value:)` с `.shake`, `.jump`, `.spin`, `.pulse`, `.ping`, `.shine` |
| Переходы | `.iris(origin:)`, `.wipe(from:)`, `.flip(axis:)`, `.pop` |
| Прокрутка | `.scrollDriven(multiplier:)` (параллакс) |
| Демо | `AnimationShowcase`, экран с по одному эффекту каждого вида |

## Быстрый старт

**1. Добавьте пакет**

В Xcode выберите **File › Add Package Dependencies…** и введите адрес репозитория:

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

Вставьте его в поле поиска в правом верхнем углу окна. Оставьте для **Dependency Rule** значение **Up to Next Major Version** начиная с `2.0.0` и нажмите **Add Package**. В следующем окне выберите таргет своего приложения рядом с **SwiftUIAnimationMasterclass** и ещё раз нажмите **Add Package**.

**2. Импортируйте модуль**

```swift
import SwiftUIAnimationMasterclass
```

**3. Используйте**

Добавьте modifier к любому view. Эта кнопка «Нравится» подпрыгивает и выпускает россыпь сердечек при каждом нажатии:

```swift
import SwiftUI
import SwiftUIAnimationMasterclass

struct LikeButton: View {
    @State private var likes = 0

    var body: some View {
        Button("Like", systemImage: "heart.fill") { likes += 1 }
            .buttonStyle(.borderedProminent)
            .changeEffect(.jump(), value: likes)
            .particleBurst(.hearts, trigger: likes)
    }
}
```

Чтобы увидеть все эффекты, не написав ни строки кода, поместите `AnimationShowcase()` в `#Preview`.

## Установка

### Swift Package Manager

В Xcode выберите **File › Add Package Dependencies…** и введите адрес репозитория:

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

Или добавьте его в `dependencies` вашего `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git", from: "2.0.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIAnimationMasterclass", package: "SwiftUI-Animation-Masterclass")
    ])
]
```

Используйте версию 2.0.0 или новее: релиз 1.0.0 не собирался.

## Использование

Все примеры ниже скопированы из [`ReadmeSamples.swift`](Examples/MotionGallery/MotionGallery/ReadmeSamples.swift); этот файл компилируют и приложение-пример, и тестовый таргет.

### Уронить значение с отскоком

`.gravityBounce()` — это `Animation`: значение падает на новую цель и отскакивает от неё.

```swift
struct DropBadge: View {
    @State private var isDropped = false

    var body: some View {
        Image(systemName: "bell.fill")
            .font(.largeTitle)
            .offset(y: isDropped ? 0 : -120)
            .animation(.gravityBounce(restitution: 0.5), value: isDropped)
            .onAppear { isDropped = true }
    }
}
```

### Праздновать с помощью частиц

`.particleBurst(_:trigger:)` выпускает залп частиц при каждом изменении значения; `.particleEffect(_:)` поддерживает эффект поверх view.

```swift
struct OrderButton: View {
    @State private var orders = 0

    var body: some View {
        Button("Place order") { orders += 1 }
            .buttonStyle(.borderedProminent)
            .particleBurst(.confetti, trigger: orders)
    }
}

struct WinterScene: View {
    var body: some View {
        LinearGradient(colors: [.indigo, .blue], startPoint: .top, endPoint: .bottom)
            .particleEffect(.snow)
            .ignoresSafeArea()
    }
}
```

### Привлечь внимание к изменению

```swift
struct PasswordField: View {
    @State private var password = ""
    @State private var failures = 0

    var body: some View {
        SecureField("Password", text: $password)
            .textFieldStyle(.roundedBorder)
            .changeEffect(.shake(), value: failures)
            .onSubmit { if password.count < 8 { failures += 1 } }
    }
}
```

### Показать и скрыть view

Переходы работают с `if` и `withAnimation`, как встроенные.

```swift
struct PhotoReveal: View {
    @State private var showsPhoto = false

    var body: some View {
        VStack {
            Button(showsPhoto ? "Hide" : "Reveal") {
                withAnimation(.smooth(duration: 0.6)) { showsPhoto.toggle() }
            }
            if showsPhoto {
                Image(systemName: "photo.artframe")
                    .font(.system(size: 120))
                    .foregroundStyle(.blue)
                    .transition(.iris(origin: .topTrailing))
            }
        }
        .frame(height: 220, alignment: .top)
    }
}
```

### Перетаскивание с импульсом

Выдвижная панель с двумя фиксированными положениями (detent): медленное отпускание возвращает её к ближайшему, бросок переводит к следующему.

```swift
struct PullUpPanel: View {
    @State private var detent = 1

    var body: some View {
        RoundedRectangle(cornerRadius: 24)
            .fill(.blue.gradient)
            .frame(height: 400)
            .overlay(alignment: .top) {
                Capsule().fill(.white.opacity(0.6)).frame(width: 40, height: 5).padding(10)
            }
            .snapDrag(.vertical, offsets: [0, 260], selection: $detent)
    }
}
```

### Создайте собственный эффект частиц

У каждого параметра эмиттера есть значение по умолчанию, поэтому задавайте только то, что отличает ваш эффект:

```swift
let stardust = ParticleEmitter(
    source: .edge(.bottom),
    birthRate: 30,
    lifetime: 2...3,
    speed: 60...120,
    direction: .degrees(-90),
    spread: .degrees(20),
    size: 6...10,
    endScale: 0.3,
    forces: [.vortex(center: .center, strength: 80), .gravity(-20)],
    colors: [.white, .cyan],
    shapes: [.star],
    fadeIn: 0.1,
    blending: .additive
)
```

## Архитектура

- В `Sources/SwiftUIAnimationMasterclass/` по одной папке на каждую область: `Physics`, `Gestures`, `Particles`, `Effects`, `Transitions`, `Scroll` и `Showcase`.
- Движение вычисляют типы-значения без кода view: `DampedSpring`, `Decay`, `GravityBounce`, `RubberBand`, `SnapPoints`, `ParticleSystem` и `ChangeEffect.state(at:)`. Modifier'ы только читают environment, хранят состояние жеста или анимации и применяют результат, поэтому математику можно проверять юнит-тестами без экрана.
- `ParticleSystem` — это struct с генератором SplitMix64: seed полностью определяет частицы на любой платформе. `ParticleView` продвигает его внутри `TimelineView` и рисует все частицы в одном `Canvas`; когда живых частиц нет, часы останавливаются.
- Значения, пришедшие из-за пределов пакета (настройки эмиттера, изменённые во время работы, длительности кадров, размеры canvas, скорости жестов), ограничиваются: нечисловые и бесконечные значения не попадают в симуляцию, а у количества частиц и отскоков есть жёсткие пределы.
- CI запускает `swift test` на macOS и `xcodebuild test` в симуляторе iPhone, собирает приложение-пример для iOS и macOS и публикует документацию DocC.

Запустите тесты локально:

```sh
swift test                                    # macOS
xcodebuild test -scheme SwiftUIAnimationMasterclass \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```
