Um pacote Swift de movimento para SwiftUI no iOS 17+ e no macOS 14+: molas baseadas em física, decay (desaceleração) e quiques, arrastos que mantêm a velocidade do dedo, efeitos de partículas, efeitos de mudança e transições. Ele é para desenvolvedores de apps que querem um efeito em uma tela sem adotar um framework: tudo é um view modifier, uma `Animation`, uma `Transition` ou um tipo de valor simples, e o pacote não tem dependências.

## Destaques

- **Física que você chama diretamente** — `DampedSpring` resolve a equação da mola em forma fechada (os testes a comparam com integração numérica), `Decay` calcula onde um gesto de arremesso termina, `GravityBounce` solta um valor e o faz quicar, e `.gravityBounce()` o executa como uma animação do SwiftUI.
- **Arrastos que mantêm o impulso** — `.elasticDrag()` e `.snapDrag(_:offsets:selection:)` passam à mola a velocidade do momento em que você solta, esticam com resistência de elástico além das extremidades e deixam um arremesso seguir até a próxima posição de repouso.
- **Partículas em um único Canvas** — 8 predefinições, 5 forças e 7 formas (incluindo SF Symbols e emoji) desenhadas por um só `Canvas`, com uma simulação com semente que gera os mesmos quadros para a mesma semente e nunca mantém mais de 10.000 partículas.
- **Efeitos de mudança e transições** — shake, jump, spin, pulse, ping e shine reproduzidos quando um valor muda, e transições iris, wipe, flip e pop sobre o protocolo `Transition` do iOS 17.
- **Suporte a Reduzir Movimento** — com essa configuração ativada, as partículas não são desenhadas, os efeitos de mudança não são reproduzidos, as transições viram um fade e os arrastos terminam com um ease-out curto.
- **Testado, Swift 6** — 70 testes do Swift Testing no macOS, 66 deles também em um simulador de iPhone, incluindo entradas NaN, infinitas e fora do intervalo; o pacote compila no modo de linguagem do Swift 6.

### O que está incluído

| Área | API |
| --- | --- |
| Física | `DampedSpring` (`gentle`, `snappy`, `bouncy`, `smooth`), `Decay`, `GravityBounce`, `.gravityBounce(fallDuration:restitution:)`, `RubberBand`, `SnapPoints` |
| Gestos | `.elasticDrag(axes:resistance:spring:)`, `.snapDrag(_:offsets:selection:decay:spring:)` |
| Partículas | `.particleBurst(_:trigger:)`, `.particleEffect(_:isActive:)`, `ParticleView`, `ParticleEmitter`, `ParticleForce`, `ParticleSystem` |
| Predefinições | `confetti`, `fireworks`, `snow`, `rain`, `sparkles`, `bubbles`, `hearts`, `embers` |
| Efeitos de mudança | `.changeEffect(_:value:)` com `.shake`, `.jump`, `.spin`, `.pulse`, `.ping`, `.shine` |
| Transições | `.iris(origin:)`, `.wipe(from:)`, `.flip(axis:)`, `.pop` |
| Rolagem | `.scrollDriven(multiplier:)` (parallax) |
| Demonstração | `AnimationShowcase`, uma tela com um efeito de cada tipo |

## Início rápido

**1. Adicione o pacote**

No Xcode, escolha **File › Add Package Dependencies…** e informe a URL do repositório:

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

Cole-a no campo de busca no canto superior direito da janela. Deixe **Dependency Rule** em **Up to Next Major Version** a partir de `2.0.0` e clique em **Add Package**. Na janela seguinte, escolha o target do seu app ao lado de **SwiftUIAnimationMasterclass** e clique em **Add Package** novamente.

**2. Importe o módulo**

```swift
import SwiftUIAnimationMasterclass
```

**3. Use**

Adicione um modifier a qualquer view. Este botão de curtir pula e solta uma rajada de corações a cada toque:

```swift
import SwiftUI
import SwiftUIAnimationMasterclass

struct LikeButton: View {
    @State private var likes = 0

    var body: some View {
        Button("Like", systemImage: "heart.fill") { likes += 1 }
            .buttonStyle(.borderedProminent)
            .changeEffect(.jump(), value: likes)
            .particleBurst(.hearts, trigger: likes)
    }
}
```

Para ver todos os efeitos antes de escrever código, coloque `AnimationShowcase()` em um `#Preview`.

## Instalação

### Swift Package Manager

No Xcode, escolha **File › Add Package Dependencies…** e informe a URL do repositório:

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

Ou adicione-o às `dependencies` do seu `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git", from: "2.0.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIAnimationMasterclass", package: "SwiftUI-Animation-Masterclass")
    ])
]
```

Use a versão 2.0.0 ou posterior: a versão 1.0.0 não compilava.

## Uso

Todos os exemplos abaixo foram copiados de [`ReadmeSamples.swift`](Examples/MotionGallery/MotionGallery/ReadmeSamples.swift), que o app de exemplo e o target de testes compilam.

### Soltar um valor com quique

`.gravityBounce()` é uma `Animation`: o valor cai até o novo destino e quica ali.

```swift
struct DropBadge: View {
    @State private var isDropped = false

    var body: some View {
        Image(systemName: "bell.fill")
            .font(.largeTitle)
            .offset(y: isDropped ? 0 : -120)
            .animation(.gravityBounce(restitution: 0.5), value: isDropped)
            .onAppear { isDropped = true }
    }
}
```

### Comemorar com partículas

`.particleBurst(_:trigger:)` emite uma rajada a cada vez que um valor muda; `.particleEffect(_:)` mantém um efeito rodando sobre uma view.

```swift
struct OrderButton: View {
    @State private var orders = 0

    var body: some View {
        Button("Place order") { orders += 1 }
            .buttonStyle(.borderedProminent)
            .particleBurst(.confetti, trigger: orders)
    }
}

struct WinterScene: View {
    var body: some View {
        LinearGradient(colors: [.indigo, .blue], startPoint: .top, endPoint: .bottom)
            .particleEffect(.snow)
            .ignoresSafeArea()
    }
}
```

### Chamar a atenção para uma mudança

```swift
struct PasswordField: View {
    @State private var password = ""
    @State private var failures = 0

    var body: some View {
        SecureField("Password", text: $password)
            .textFieldStyle(.roundedBorder)
            .changeEffect(.shake(), value: failures)
            .onSubmit { if password.count < 8 { failures += 1 } }
    }
}
```

### Mostrar e ocultar views

As transições funcionam com `if` e `withAnimation` como as nativas.

```swift
struct PhotoReveal: View {
    @State private var showsPhoto = false

    var body: some View {
        VStack {
            Button(showsPhoto ? "Hide" : "Reveal") {
                withAnimation(.smooth(duration: 0.6)) { showsPhoto.toggle() }
            }
            if showsPhoto {
                Image(systemName: "photo.artframe")
                    .font(.system(size: 120))
                    .foregroundStyle(.blue)
                    .transition(.iris(origin: .topTrailing))
            }
        }
        .frame(height: 220, alignment: .top)
    }
}
```

### Arrastar com impulso

Um painel de puxar para cima com duas posições de parada (detents): soltar devagar volta à mais próxima, um arremesso vai para a seguinte.

```swift
struct PullUpPanel: View {
    @State private var detent = 1

    var body: some View {
        RoundedRectangle(cornerRadius: 24)
            .fill(.blue.gradient)
            .frame(height: 400)
            .overlay(alignment: .top) {
                Capsule().fill(.white.opacity(0.6)).frame(width: 40, height: 5).padding(10)
            }
            .snapDrag(.vertical, offsets: [0, 260], selection: $detent)
    }
}
```

### Criar seu próprio efeito de partículas

Todo parâmetro do emissor tem um valor padrão, então defina apenas o que torna o efeito diferente:

```swift
let stardust = ParticleEmitter(
    source: .edge(.bottom),
    birthRate: 30,
    lifetime: 2...3,
    speed: 60...120,
    direction: .degrees(-90),
    spread: .degrees(20),
    size: 6...10,
    endScale: 0.3,
    forces: [.vortex(center: .center, strength: 80), .gravity(-20)],
    colors: [.white, .cyan],
    shapes: [.star],
    fadeIn: 0.1,
    blending: .additive
)
```

## Arquitetura

- `Sources/SwiftUIAnimationMasterclass/` tem uma pasta por área: `Physics`, `Gestures`, `Particles`, `Effects`, `Transitions`, `Scroll` e `Showcase`.
- O movimento é calculado por tipos de valor sem código de view: `DampedSpring`, `Decay`, `GravityBounce`, `RubberBand`, `SnapPoints`, `ParticleSystem` e `ChangeEffect.state(at:)`. Os modifiers apenas leem o ambiente, guardam o estado do gesto ou da animação e aplicam o resultado, de modo que a matemática é testada por testes unitários sem precisar de uma tela.
- `ParticleSystem` é um struct com um gerador SplitMix64: uma semente determina por completo as partículas em qualquer plataforma. `ParticleView` o avança dentro de uma `TimelineView` e desenha todas as partículas em um único `Canvas`; o relógio pausa quando não há nada vivo.
- Valores vindos de fora do pacote (configurações do emissor alteradas em tempo de execução, tempos de quadro, tamanhos do canvas, velocidades de gestos) são limitados: números não finitos não chegam à simulação, e as quantidades de partículas e de quiques têm limites rígidos.
- O CI executa `swift test` no macOS e `xcodebuild test` em um simulador de iPhone, compila o app de exemplo para iOS e macOS e publica a documentação DocC.

Execute os testes localmente:

```sh
swift test                                    # macOS
xcodebuild test -scheme SwiftUIAnimationMasterclass \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```
