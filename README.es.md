Un paquete de Swift con movimiento para SwiftUI en iOS 17+ y macOS 14+: muelles basados en física, decay (deceleración) y rebotes, arrastres que conservan la velocidad del dedo, efectos de partículas, efectos de cambio y transiciones. Está pensado para desarrolladores de apps que quieren un efecto en una pantalla sin adoptar un framework: todo es un view modifier, una `Animation`, una `Transition` o un tipo de valor sencillo, y el paquete no tiene dependencias.

## Lo más destacado

- **Física que puedes llamar directamente** — `DampedSpring` resuelve la ecuación del muelle en forma cerrada (las pruebas la comparan con una integración numérica), `Decay` calcula dónde termina un gesto de lanzamiento, `GravityBounce` deja caer un valor y lo hace rebotar, y `.gravityBounce()` lo ejecuta como una animación de SwiftUI.
- **Arrastres que conservan su impulso** — `.elasticDrag()` y `.snapDrag(_:offsets:selection:)` pasan al muelle la velocidad con la que se suelta, se estiran con resistencia de goma al pasar de los extremos y permiten que un lanzamiento continúe hasta la siguiente posición de reposo.
- **Partículas en un único Canvas** — 8 ajustes preestablecidos, 5 fuerzas y 7 formas (incluidos SF Symbols y emoji) dibujados con un solo `Canvas`, con una simulación con semilla que genera los mismos fotogramas para la misma semilla y que nunca mantiene más de 10 000 partículas.
- **Efectos de cambio y transiciones** — shake, jump, spin, pulse, ping y shine que se reproducen cuando cambia un valor, y transiciones iris, wipe, flip y pop sobre el protocolo `Transition` de iOS 17.
- **Compatible con Reducir movimiento** — con este ajuste activado no se dibujan partículas, los efectos de cambio no se reproducen, las transiciones se desvanecen y los arrastres se detienen con un ease-out breve.
- **Probado, Swift 6** — 70 pruebas de Swift Testing en macOS, 66 de ellas también en un simulador de iPhone, incluidas entradas NaN, infinitas y fuera de rango; el paquete compila en el modo de lenguaje de Swift 6.

### Qué incluye

| Área | API |
| --- | --- |
| Física | `DampedSpring` (`gentle`, `snappy`, `bouncy`, `smooth`), `Decay`, `GravityBounce`, `.gravityBounce(fallDuration:restitution:)`, `RubberBand`, `SnapPoints` |
| Gestos | `.elasticDrag(axes:resistance:spring:)`, `.snapDrag(_:offsets:selection:decay:spring:)` |
| Partículas | `.particleBurst(_:trigger:)`, `.particleEffect(_:isActive:)`, `ParticleView`, `ParticleEmitter`, `ParticleForce`, `ParticleSystem` |
| Preajustes | `confetti`, `fireworks`, `snow`, `rain`, `sparkles`, `bubbles`, `hearts`, `embers` |
| Efectos de cambio | `.changeEffect(_:value:)` con `.shake`, `.jump`, `.spin`, `.pulse`, `.ping`, `.shine` |
| Transiciones | `.iris(origin:)`, `.wipe(from:)`, `.flip(axis:)`, `.pop` |
| Desplazamiento | `.scrollDriven(multiplier:)` (parallax) |
| Demo | `AnimationShowcase`, una pantalla con un efecto de cada tipo |

## Inicio rápido

**1. Añade el paquete**

En Xcode, elige **File › Add Package Dependencies…** e introduce la URL del repositorio:

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

Pégala en el campo de búsqueda de la parte superior derecha de la ventana. Deja **Dependency Rule** en **Up to Next Major Version** desde `2.0.0` y haz clic en **Add Package**. En la ventana siguiente, elige el target de tu app junto a **SwiftUIAnimationMasterclass** y haz clic de nuevo en **Add Package**.

**2. Importa el módulo**

```swift
import SwiftUIAnimationMasterclass
```

**3. Úsalo**

Añade un modifier a cualquier vista. Este botón de «me gusta» salta y lanza una ráfaga de corazones en cada toque:

```swift
import SwiftUI
import SwiftUIAnimationMasterclass

struct LikeButton: View {
    @State private var likes = 0

    var body: some View {
        Button("Like", systemImage: "heart.fill") { likes += 1 }
            .buttonStyle(.borderedProminent)
            .changeEffect(.jump(), value: likes)
            .particleBurst(.hearts, trigger: likes)
    }
}
```

Para ver todos los efectos antes de escribir código, pon `AnimationShowcase()` en un `#Preview`.

## Instalación

### Swift Package Manager

En Xcode, elige **File › Add Package Dependencies…** e introduce la URL del repositorio:

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

O añádelo a las `dependencies` de tu `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git", from: "2.0.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIAnimationMasterclass", package: "SwiftUI-Animation-Masterclass")
    ])
]
```

Usa la versión 2.0.0 o posterior: la versión 1.0.0 no compilaba.

## Uso

Todos los ejemplos siguientes están copiados de [`ReadmeSamples.swift`](Examples/MotionGallery/MotionGallery/ReadmeSamples.swift), que compilan tanto la app de ejemplo como el target de pruebas.

### Deja caer un valor con rebote

`.gravityBounce()` es una `Animation`: el valor cae hasta su nuevo destino y rebota allí.

```swift
struct DropBadge: View {
    @State private var isDropped = false

    var body: some View {
        Image(systemName: "bell.fill")
            .font(.largeTitle)
            .offset(y: isDropped ? 0 : -120)
            .animation(.gravityBounce(restitution: 0.5), value: isDropped)
            .onAppear { isDropped = true }
    }
}
```

### Celebra con partículas

`.particleBurst(_:trigger:)` emite una ráfaga cada vez que cambia un valor; `.particleEffect(_:)` mantiene un efecto activo sobre una vista.

```swift
struct OrderButton: View {
    @State private var orders = 0

    var body: some View {
        Button("Place order") { orders += 1 }
            .buttonStyle(.borderedProminent)
            .particleBurst(.confetti, trigger: orders)
    }
}

struct WinterScene: View {
    var body: some View {
        LinearGradient(colors: [.indigo, .blue], startPoint: .top, endPoint: .bottom)
            .particleEffect(.snow)
            .ignoresSafeArea()
    }
}
```

### Llama la atención sobre un cambio

```swift
struct PasswordField: View {
    @State private var password = ""
    @State private var failures = 0

    var body: some View {
        SecureField("Password", text: $password)
            .textFieldStyle(.roundedBorder)
            .changeEffect(.shake(), value: failures)
            .onSubmit { if password.count < 8 { failures += 1 } }
    }
}
```

### Muestra y oculta vistas

Las transiciones funcionan con `if` y `withAnimation` igual que las integradas.

```swift
struct PhotoReveal: View {
    @State private var showsPhoto = false

    var body: some View {
        VStack {
            Button(showsPhoto ? "Hide" : "Reveal") {
                withAnimation(.smooth(duration: 0.6)) { showsPhoto.toggle() }
            }
            if showsPhoto {
                Image(systemName: "photo.artframe")
                    .font(.system(size: 120))
                    .foregroundStyle(.blue)
                    .transition(.iris(origin: .topTrailing))
            }
        }
        .frame(height: 220, alignment: .top)
    }
}
```

### Arrastra con impulso

Un panel que se desliza hacia arriba con dos posiciones de parada (detents): si lo sueltas despacio, vuelve a la más cercana; si lo lanzas, pasa a la siguiente.

```swift
struct PullUpPanel: View {
    @State private var detent = 1

    var body: some View {
        RoundedRectangle(cornerRadius: 24)
            .fill(.blue.gradient)
            .frame(height: 400)
            .overlay(alignment: .top) {
                Capsule().fill(.white.opacity(0.6)).frame(width: 40, height: 5).padding(10)
            }
            .snapDrag(.vertical, offsets: [0, 260], selection: $detent)
    }
}
```

### Diseña tu propio efecto de partículas

Todos los parámetros del emisor tienen un valor por defecto, así que configura solo lo que hace diferente al efecto:

```swift
let stardust = ParticleEmitter(
    source: .edge(.bottom),
    birthRate: 30,
    lifetime: 2...3,
    speed: 60...120,
    direction: .degrees(-90),
    spread: .degrees(20),
    size: 6...10,
    endScale: 0.3,
    forces: [.vortex(center: .center, strength: 80), .gravity(-20)],
    colors: [.white, .cyan],
    shapes: [.star],
    fadeIn: 0.1,
    blending: .additive
)
```

## Arquitectura

- `Sources/SwiftUIAnimationMasterclass/` tiene una carpeta por área: `Physics`, `Gestures`, `Particles`, `Effects`, `Transitions`, `Scroll` y `Showcase`.
- El movimiento lo calculan tipos de valor sin código de vistas: `DampedSpring`, `Decay`, `GravityBounce`, `RubberBand`, `SnapPoints`, `ParticleSystem` y `ChangeEffect.state(at:)`. Los modifiers solo leen el entorno, guardan el estado del gesto o de la animación y aplican el resultado, de modo que las matemáticas se prueban con tests unitarios sin necesidad de pantalla.
- `ParticleSystem` es un struct con un generador SplitMix64: una semilla determina por completo las partículas en cualquier plataforma. `ParticleView` lo hace avanzar dentro de un `TimelineView` y dibuja todas las partículas en un solo `Canvas`; el reloj se detiene cuando no queda ninguna viva.
- Los valores que vienen de fuera del paquete (ajustes del emisor cambiados en tiempo de ejecución, tiempos de fotograma, tamaños del canvas, velocidades de los gestos) se acotan: los números no finitos no llegan a la simulación, y el número de partículas y de rebotes tiene límites estrictos.
- CI ejecuta `swift test` en macOS y `xcodebuild test` en un simulador de iPhone, compila la app de ejemplo para iOS y macOS, y publica la documentación de DocC.

Ejecuta las pruebas en local:

```sh
swift test                                    # macOS
xcodebuild test -scheme SwiftUIAnimationMasterclass \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```
