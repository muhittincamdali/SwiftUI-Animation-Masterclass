iOS 17+와 macOS 14+의 SwiftUI를 위한 모션 Swift 패키지입니다. 물리 기반 스프링, 감쇠(decay)와 바운스, 손가락의 속도를 이어받는 드래그, 파티클 효과, 변화 효과, 전환을 제공합니다. 프레임워크를 통째로 도입하지 않고 한 화면에 효과 하나만 넣고 싶은 앱 개발자를 위한 패키지입니다. 모든 기능은 view modifier, `Animation`, `Transition` 또는 단순한 값 타입이며, 패키지에는 의존성이 없습니다.

## 주요 기능

- **직접 호출할 수 있는 물리 계산** — `DampedSpring`은 스프링 방정식을 닫힌 형태로 풀고(테스트에서 수치 적분과 비교합니다), `Decay`는 플릭이 어디서 멈출지 예측하며, `GravityBounce`는 값을 떨어뜨려 튕기게 하고, `.gravityBounce()`는 이를 SwiftUI 애니메이션으로 실행합니다.
- **관성을 유지하는 드래그** — `.elasticDrag()`와 `.snapDrag(_:offsets:selection:)`는 손을 뗄 때의 속도를 스프링에 전달하고, 끝을 넘어서면 고무줄처럼 저항하며 늘어나고, 플릭하면 다음 정지 위치까지 이어서 움직입니다.
- **하나의 Canvas로 그리는 파티클** — 프리셋 8개, 힘 5개, 모양 7개(SF Symbols와 emoji 포함)를 하나의 `Canvas`로 그립니다. 시드를 쓰는 시뮬레이션은 같은 시드에서 같은 프레임을 만들며, 파티클은 10,000개를 넘지 않습니다.
- **변화 효과와 전환** — 값이 바뀔 때 재생되는 shake, jump, spin, pulse, ping, shine 효과와, iOS 17 `Transition` 프로토콜 기반의 iris, wipe, flip, pop 전환.
- **동작 줄이기 지원** — 이 설정이 켜져 있으면 파티클을 그리지 않고, 변화 효과를 재생하지 않으며, 전환은 페이드로 바뀌고, 드래그는 짧은 ease-out으로 멈춥니다.
- **테스트 완료, Swift 6** — macOS와 iPhone 시뮬레이터에서 Swift Testing 테스트 63개를 실행하며, NaN, 무한대, 범위를 벗어난 입력도 포함합니다. 패키지는 Swift 6 언어 모드로 빌드됩니다.

### 포함된 기능

| 영역 | API |
| --- | --- |
| 물리 | `DampedSpring` (`gentle`, `snappy`, `bouncy`, `smooth`), `Decay`, `GravityBounce`, `.gravityBounce(fallDuration:restitution:)`, `RubberBand`, `SnapPoints` |
| 제스처 | `.elasticDrag(axes:resistance:spring:)`, `.snapDrag(_:offsets:selection:decay:spring:)` |
| 파티클 | `.particleBurst(_:trigger:)`, `.particleEffect(_:isActive:)`, `ParticleView`, `ParticleEmitter`, `ParticleForce`, `ParticleSystem` |
| 프리셋 | `confetti`, `fireworks`, `snow`, `rain`, `sparkles`, `bubbles`, `hearts`, `embers` |
| 변화 효과 | `.changeEffect(_:value:)` 와 함께 `.shake`, `.jump`, `.spin`, `.pulse`, `.ping`, `.shine` |
| 전환 | `.iris(origin:)`, `.wipe(from:)`, `.flip(axis:)`, `.pop` |
| 스크롤 | `.scrollDriven(multiplier:)` (패럴랙스) |
| 데모 | `AnimationShowcase`, 종류별로 효과 하나씩을 담은 화면 |

## 빠른 시작

**1. 패키지 추가**

Xcode에서 **File › Add Package Dependencies…**를 선택하고 저장소 URL을 입력하세요.

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

창 오른쪽 위의 검색란에 붙여넣으세요. **Dependency Rule**은 `2.0.0`부터 **Up to Next Major Version**으로 둔 채 **Add Package**를 클릭합니다. 다음 창에서 **SwiftUIAnimationMasterclass** 옆에 있는 앱 타깃을 선택하고 **Add Package**를 다시 클릭합니다.

**2. 모듈 가져오기**

```swift
import SwiftUIAnimationMasterclass
```

**3. 사용하기**

어떤 view에든 modifier를 추가하세요. 이 좋아요 버튼은 탭할 때마다 튀어 오르며 하트를 흩뿌립니다.

```swift
import SwiftUI
import SwiftUIAnimationMasterclass

struct LikeButton: View {
    @State private var likes = 0

    var body: some View {
        Button("Like", systemImage: "heart.fill") { likes += 1 }
            .buttonStyle(.borderedProminent)
            .changeEffect(.jump(), value: likes)
            .particleBurst(.hearts, trigger: likes)
    }
}
```

코드를 쓰기 전에 모든 효과를 보려면 `#Preview`에 `AnimationShowcase()`를 넣으세요.

## 사용법

아래 샘플은 모두 [`ReadmeSamples.swift`](Examples/MotionGallery/MotionGallery/ReadmeSamples.swift)에서 복사한 것이며, 이 파일은 예제 앱과 테스트 타깃이 컴파일합니다.

### 값을 바운스와 함께 떨어뜨리기

`.gravityBounce()`는 `Animation`입니다. 값이 새 목표 위치로 떨어져 그곳에서 튕깁니다.

```swift
struct DropBadge: View {
    @State private var isDropped = false

    var body: some View {
        Image(systemName: "bell.fill")
            .font(.largeTitle)
            .offset(y: isDropped ? 0 : -120)
            .animation(.gravityBounce(restitution: 0.5), value: isDropped)
            .onAppear { isDropped = true }
    }
}
```

### 파티클로 축하하기

`.particleBurst(_:trigger:)`는 값이 바뀔 때마다 파티클을 터뜨리고, `.particleEffect(_:)`는 view 위에서 효과를 계속 실행합니다.

```swift
struct OrderButton: View {
    @State private var orders = 0

    var body: some View {
        Button("Place order") { orders += 1 }
            .buttonStyle(.borderedProminent)
            .particleBurst(.confetti, trigger: orders)
    }
}

struct WinterScene: View {
    var body: some View {
        LinearGradient(colors: [.indigo, .blue], startPoint: .top, endPoint: .bottom)
            .particleEffect(.snow)
            .ignoresSafeArea()
    }
}
```

### 변화에 주목시키기

```swift
struct PasswordField: View {
    @State private var password = ""
    @State private var failures = 0

    var body: some View {
        SecureField("Password", text: $password)
            .textFieldStyle(.roundedBorder)
            .changeEffect(.shake(), value: failures)
            .onSubmit { if password.count < 8 { failures += 1 } }
    }
}
```

### view 보이기와 숨기기

전환은 기본 제공 전환처럼 `if` 및 `withAnimation`과 함께 동작합니다.

```swift
struct PhotoReveal: View {
    @State private var showsPhoto = false

    var body: some View {
        VStack {
            Button(showsPhoto ? "Hide" : "Reveal") {
                withAnimation(.smooth(duration: 0.6)) { showsPhoto.toggle() }
            }
            if showsPhoto {
                Image(systemName: "photo.artframe")
                    .font(.system(size: 120))
                    .foregroundStyle(.blue)
                    .transition(.iris(origin: .topTrailing))
            }
        }
        .frame(height: 220, alignment: .top)
    }
}
```

### 관성이 있는 드래그

정지 위치(detent)가 두 개인 끌어올리는 패널입니다. 천천히 놓으면 가장 가까운 위치로 돌아가고, 플릭하면 다음 위치로 넘어갑니다.

```swift
struct PullUpPanel: View {
    @State private var detent = 1

    var body: some View {
        RoundedRectangle(cornerRadius: 24)
            .fill(.blue.gradient)
            .frame(height: 400)
            .overlay(alignment: .top) {
                Capsule().fill(.white.opacity(0.6)).frame(width: 40, height: 5).padding(10)
            }
            .snapDrag(.vertical, offsets: [0, 260], selection: $detent)
    }
}
```

### 나만의 파티클 효과 만들기

emitter의 모든 파라미터에는 기본값이 있으므로, 효과를 다르게 만드는 값만 설정하면 됩니다.

```swift
let stardust = ParticleEmitter(
    source: .edge(.bottom),
    birthRate: 30,
    lifetime: 2...3,
    speed: 60...120,
    direction: .degrees(-90),
    spread: .degrees(20),
    size: 6...10,
    endScale: 0.3,
    forces: [.vortex(center: .center, strength: 80), .gravity(-20)],
    colors: [.white, .cyan],
    shapes: [.star],
    fadeIn: 0.1,
    blending: .additive
)
```

## 아키텍처

- `Sources/SwiftUIAnimationMasterclass/`에는 영역마다 폴더가 하나씩 있습니다: `Physics`, `Gestures`, `Particles`, `Effects`, `Transitions`, `Scroll`, `Showcase`.
- 모션은 view 코드가 없는 값 타입이 계산합니다: `DampedSpring`, `Decay`, `GravityBounce`, `RubberBand`, `SnapPoints`, `ParticleSystem`, `ChangeEffect.state(at:)`. modifier는 environment를 읽고, 제스처나 애니메이션의 상태를 보관하며, 결과를 적용할 뿐이므로 수학 부분은 화면 없이 단위 테스트할 수 있습니다.
- `ParticleSystem`은 SplitMix64 생성기를 쓰는 struct이며, 시드가 모든 플랫폼에서 파티클을 완전히 결정합니다. `ParticleView`는 `TimelineView` 안에서 이를 진행시키고 모든 파티클을 하나의 `Canvas`에 그리며, 살아 있는 파티클이 없으면 클록이 멈춥니다.
- 패키지 밖에서 들어오는 값(실행 중에 바뀌는 emitter 설정, 프레임 시간, canvas 크기, 제스처 속도)은 범위가 제한됩니다. 유한하지 않은 수는 시뮬레이션에 도달하지 않으며, 파티클 수와 바운스 횟수에는 엄격한 상한이 있습니다.
- CI는 macOS에서 `swift test`를, iPhone 시뮬레이터에서 `xcodebuild test`를 실행하고, 예제 앱을 iOS와 macOS용으로 빌드하며, DocC 문서를 게시합니다.

테스트를 로컬에서 실행하려면:

```sh
swift test                                    # macOS
xcodebuild test -scheme SwiftUIAnimationMasterclass \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```
