Ein Swift-Paket für Bewegung in SwiftUI auf iOS 17+ und macOS 14+: physikbasierte Federn, Decay (Ausklingen) und Abprallen, Drag-Gesten, die die Geschwindigkeit des Fingers beibehalten, Partikeleffekte, Änderungseffekte und Übergänge. Es richtet sich an App-Entwickler, die auf einem Bildschirm einen Effekt haben möchten, ohne ein Framework einzuführen: Alles ist ein View-Modifier, eine `Animation`, eine `Transition` oder ein einfacher Werttyp, und das Paket hat keine Abhängigkeiten.

## Highlights

- **Physik, die du direkt aufrufen kannst** — `DampedSpring` löst die Federgleichung in geschlossener Form (Tests vergleichen das Ergebnis mit numerischer Integration), `Decay` berechnet, wo eine Wischbewegung zur Ruhe kommt, `GravityBounce` lässt einen Wert fallen und aufprallen, und `.gravityBounce()` führt das als SwiftUI-Animation aus.
- **Drag-Gesten mit Schwung** — `.elasticDrag()` und `.snapDrag(_:offsets:selection:)` geben die Loslass-Geschwindigkeit an die Feder weiter, dehnen sich jenseits der Enden mit Gummiband-Widerstand und lassen eine Wischbewegung bis zur nächsten Ruheposition weiterlaufen.
- **Partikel in einem einzigen Canvas** — 8 Presets, 5 Kräfte und 7 Formen (einschließlich SF Symbols und Emoji), gezeichnet von einem `Canvas`. Die Simulation mit Seed liefert bei gleichem Seed dieselben Frames und hält nie mehr als 10.000 Partikel.
- **Änderungseffekte und Übergänge** — shake, jump, spin, pulse, ping und shine, die beim Ändern eines Werts abgespielt werden, sowie die Übergänge iris, wipe, flip und pop auf Basis des `Transition`-Protokolls von iOS 17.
- **Bewegung reduzieren wird beachtet** — Ist die Einstellung aktiv, werden keine Partikel gezeichnet, Änderungseffekte nicht abgespielt, Übergänge blenden über und Drag-Gesten kommen mit einem kurzen Ease-out zur Ruhe.
- **Getestet, Swift 6** — 63 Swift-Testing-Tests auf macOS und in einem iPhone-Simulator, auch mit NaN, unendlichen und außerhalb des Bereichs liegenden Eingaben; das Paket baut im Swift-6-Sprachmodus.

### Lieferumfang

| Bereich | API |
| --- | --- |
| Physik | `DampedSpring` (`gentle`, `snappy`, `bouncy`, `smooth`), `Decay`, `GravityBounce`, `.gravityBounce(fallDuration:restitution:)`, `RubberBand`, `SnapPoints` |
| Gesten | `.elasticDrag(axes:resistance:spring:)`, `.snapDrag(_:offsets:selection:decay:spring:)` |
| Partikel | `.particleBurst(_:trigger:)`, `.particleEffect(_:isActive:)`, `ParticleView`, `ParticleEmitter`, `ParticleForce`, `ParticleSystem` |
| Presets | `confetti`, `fireworks`, `snow`, `rain`, `sparkles`, `bubbles`, `hearts`, `embers` |
| Änderungseffekte | `.changeEffect(_:value:)` mit `.shake`, `.jump`, `.spin`, `.pulse`, `.ping`, `.shine` |
| Übergänge | `.iris(origin:)`, `.wipe(from:)`, `.flip(axis:)`, `.pop` |
| Scrollen | `.scrollDriven(multiplier:)` (Parallaxe) |
| Demo | `AnimationShowcase`, ein Bildschirm mit je einem Effekt jeder Art |

## Schnellstart

**1. Paket hinzufügen**

Wähle in Xcode **File › Add Package Dependencies…** und gib die Repository-URL ein:

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

Füge sie oben rechts im Fenster in das Suchfeld ein. Lass **Dependency Rule** auf **Up to Next Major Version** ab `2.0.0` stehen und klicke auf **Add Package**. Wähle im nächsten Fenster neben **SwiftUIAnimationMasterclass** dein App-Target aus und klicke erneut auf **Add Package**.

**2. Modul importieren**

```swift
import SwiftUIAnimationMasterclass
```

**3. Verwenden**

Füge einer beliebigen View einen Modifier hinzu. Dieser Like-Button springt bei jedem Tippen und lässt eine Salve von Herzen aufsteigen:

```swift
import SwiftUI
import SwiftUIAnimationMasterclass

struct LikeButton: View {
    @State private var likes = 0

    var body: some View {
        Button("Like", systemImage: "heart.fill") { likes += 1 }
            .buttonStyle(.borderedProminent)
            .changeEffect(.jump(), value: likes)
            .particleBurst(.hearts, trigger: likes)
    }
}
```

Um alle Effekte zu sehen, bevor du Code schreibst, setze `AnimationShowcase()` in ein `#Preview`.

## Installation

### Swift Package Manager

Wähle in Xcode **File › Add Package Dependencies…** und gib die Repository-URL ein:

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

Oder füge es zu den `dependencies` in deiner `Package.swift` hinzu:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git", from: "2.0.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIAnimationMasterclass", package: "SwiftUI-Animation-Masterclass")
    ])
]
```

Verwende 2.0.0 oder neuer: Das Release 1.0.0 ließ sich nicht bauen.

## Verwendung

Jedes der folgenden Beispiele ist aus [`ReadmeSamples.swift`](Examples/MotionGallery/MotionGallery/ReadmeSamples.swift) kopiert; diese Datei kompilieren die Beispiel-App und das Test-Target.

### Einen Wert mit Aufprall fallen lassen

`.gravityBounce()` ist eine `Animation`: Der Wert fällt auf sein neues Ziel und prallt dort ab.

```swift
struct DropBadge: View {
    @State private var isDropped = false

    var body: some View {
        Image(systemName: "bell.fill")
            .font(.largeTitle)
            .offset(y: isDropped ? 0 : -120)
            .animation(.gravityBounce(restitution: 0.5), value: isDropped)
            .onAppear { isDropped = true }
    }
}
```

### Mit Partikeln feiern

`.particleBurst(_:trigger:)` löst bei jeder Wertänderung einen Ausbruch aus; `.particleEffect(_:)` lässt einen Effekt dauerhaft über einer View laufen.

```swift
struct OrderButton: View {
    @State private var orders = 0

    var body: some View {
        Button("Place order") { orders += 1 }
            .buttonStyle(.borderedProminent)
            .particleBurst(.confetti, trigger: orders)
    }
}

struct WinterScene: View {
    var body: some View {
        LinearGradient(colors: [.indigo, .blue], startPoint: .top, endPoint: .bottom)
            .particleEffect(.snow)
            .ignoresSafeArea()
    }
}
```

### Auf eine Änderung aufmerksam machen

```swift
struct PasswordField: View {
    @State private var password = ""
    @State private var failures = 0

    var body: some View {
        SecureField("Password", text: $password)
            .textFieldStyle(.roundedBorder)
            .changeEffect(.shake(), value: failures)
            .onSubmit { if password.count < 8 { failures += 1 } }
    }
}
```

### Views ein- und ausblenden

Die Übergänge funktionieren wie die eingebauten mit `if` und `withAnimation`.

```swift
struct PhotoReveal: View {
    @State private var showsPhoto = false

    var body: some View {
        VStack {
            Button(showsPhoto ? "Hide" : "Reveal") {
                withAnimation(.smooth(duration: 0.6)) { showsPhoto.toggle() }
            }
            if showsPhoto {
                Image(systemName: "photo.artframe")
                    .font(.system(size: 120))
                    .foregroundStyle(.blue)
                    .transition(.iris(origin: .topTrailing))
            }
        }
        .frame(height: 220, alignment: .top)
    }
}
```

### Mit Schwung ziehen

Ein Pull-up-Panel mit zwei Rastpunkten (Detents): Langsames Loslassen führt zum nächstgelegenen zurück, eine Wischbewegung springt weiter.

```swift
struct PullUpPanel: View {
    @State private var detent = 1

    var body: some View {
        RoundedRectangle(cornerRadius: 24)
            .fill(.blue.gradient)
            .frame(height: 400)
            .overlay(alignment: .top) {
                Capsule().fill(.white.opacity(0.6)).frame(width: 40, height: 5).padding(10)
            }
            .snapDrag(.vertical, offsets: [0, 260], selection: $detent)
    }
}
```

### Eigenen Partikeleffekt gestalten

Jeder Parameter des Emitters hat einen Standardwert; setze also nur, was den Effekt besonders macht:

```swift
let stardust = ParticleEmitter(
    source: .edge(.bottom),
    birthRate: 30,
    lifetime: 2...3,
    speed: 60...120,
    direction: .degrees(-90),
    spread: .degrees(20),
    size: 6...10,
    endScale: 0.3,
    forces: [.vortex(center: .center, strength: 80), .gravity(-20)],
    colors: [.white, .cyan],
    shapes: [.star],
    fadeIn: 0.1,
    blending: .additive
)
```

## Architektur

- `Sources/SwiftUIAnimationMasterclass/` enthält einen Ordner pro Bereich: `Physics`, `Gestures`, `Particles`, `Effects`, `Transitions`, `Scroll` und `Showcase`.
- Die Bewegung berechnen Werttypen ohne View-Code: `DampedSpring`, `Decay`, `GravityBounce`, `RubberBand`, `SnapPoints`, `ParticleSystem` und `ChangeEffect.state(at:)`. Die Modifier lesen nur das Environment, halten den Gesten- oder Animationszustand und wenden das Ergebnis an, sodass sich die Mathematik ohne Bildschirm per Unit-Test prüfen lässt.
- `ParticleSystem` ist ein Struct mit einem SplitMix64-Generator: Ein Seed bestimmt die Partikel auf jeder Plattform vollständig. `ParticleView` lässt es in einer `TimelineView` weiterlaufen und zeichnet alle Partikel in einen `Canvas`; die Uhr pausiert, wenn nichts mehr lebt.
- Werte von außerhalb des Pakets (zur Laufzeit geänderte Emitter-Einstellungen, Frame-Zeiten, Canvas-Größen, Gestengeschwindigkeiten) werden begrenzt: Nicht endliche Zahlen erreichen die Simulation nicht, und für Partikel- und Aufprallanzahlen gelten feste Obergrenzen.
- CI führt `swift test` auf macOS und `xcodebuild test` in einem iPhone-Simulator aus, baut die Beispiel-App für iOS und macOS und veröffentlicht die DocC-Dokumentation.

Die Tests lokal ausführen:

```sh
swift test                                    # macOS
xcodebuild test -scheme SwiftUIAnimationMasterclass \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```
