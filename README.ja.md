iOS 17+ と macOS 14+ の SwiftUI 向けのモーション Swift パッケージです。物理ベースのスプリング、減衰（decay）とバウンス、指の速度を引き継ぐドラッグ、パーティクルエフェクト、変化エフェクト、トランジションを提供します。フレームワークを丸ごと導入せずに、1 つの画面にエフェクトを加えたいアプリ開発者向けです。すべての機能は view modifier、`Animation`、`Transition`、またはシンプルな値型で、パッケージに依存関係はありません。

## 主な特長

- **直接呼び出せる物理計算** — `DampedSpring` はバネの方程式を閉じた形で解きます（テストで数値積分の結果と比較しています）。`Decay` はフリックがどこで止まるかを予測し、`GravityBounce` は値を落としてバウンドさせ、`.gravityBounce()` はそれを SwiftUI のアニメーションとして実行します。
- **勢いを保つドラッグ** — `.elasticDrag()` と `.snapDrag(_:offsets:selection:)` は、指を離したときの速度をスプリングに渡し、端を越えるとゴムのような抵抗で伸び、フリックで次の静止位置まで進めます。
- **1 つの Canvas で描くパーティクル** — 8 種類のプリセット、5 種類の力、7 種類の形状（SF Symbols と emoji を含む）を 1 つの `Canvas` で描画します。シード付きのシミュレーションは、同じシードなら同じフレームを生成し、パーティクルが 10,000 個を超えることはありません。
- **変化エフェクトとトランジション** — 値が変わったときに再生される shake、jump、spin、pulse、ping、shine と、iOS 17 の `Transition` プロトコルに基づく iris、wipe、flip、pop トランジション。
- **視差効果を減らす設定に対応** — この設定がオンのときは、パーティクルは描画されず、変化エフェクトは再生されず、トランジションはフェードになり、ドラッグは短い ease-out で落ち着きます。
- **テスト済み、Swift 6** — macOS で 70 件の Swift Testing テストを実行し、そのうち 66 件は iPhone シミュレータでも実行します。NaN、無限大、範囲外の入力も含みます。パッケージは Swift 6 言語モードでビルドできます。

### 収録内容

| 領域 | API |
| --- | --- |
| 物理 | `DampedSpring` (`gentle`, `snappy`, `bouncy`, `smooth`), `Decay`, `GravityBounce`, `.gravityBounce(fallDuration:restitution:)`, `RubberBand`, `SnapPoints` |
| ジェスチャ | `.elasticDrag(axes:resistance:spring:)`, `.snapDrag(_:offsets:selection:decay:spring:)` |
| パーティクル | `.particleBurst(_:trigger:)`, `.particleEffect(_:isActive:)`, `ParticleView`, `ParticleEmitter`, `ParticleForce`, `ParticleSystem` |
| プリセット | `confetti`, `fireworks`, `snow`, `rain`, `sparkles`, `bubbles`, `hearts`, `embers` |
| 変化エフェクト | `.changeEffect(_:value:)` と `.shake`, `.jump`, `.spin`, `.pulse`, `.ping`, `.shine` |
| トランジション | `.iris(origin:)`, `.wipe(from:)`, `.flip(axis:)`, `.pop` |
| スクロール | `.scrollDriven(multiplier:)` （パララックス） |
| デモ | `AnimationShowcase`、各種類のエフェクトを 1 つずつ並べた画面 |

## クイックスタート

**1. パッケージを追加する**

Xcode で **File › Add Package Dependencies…** を選び、リポジトリの URL を入力します。

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

ウィンドウ右上の検索欄に貼り付けます。**Dependency Rule** は `2.0.0` からの **Up to Next Major Version** のままにして、**Add Package** をクリックします。次のウィンドウで **SwiftUIAnimationMasterclass** の横にあるアプリのターゲットを選び、もう一度 **Add Package** をクリックします。

**2. モジュールをインポートする**

```swift
import SwiftUIAnimationMasterclass
```

**3. 使ってみる**

任意の view に modifier を追加します。この「いいね」ボタンは、タップするたびに跳ねてハートを舞い上げます。

```swift
import SwiftUI
import SwiftUIAnimationMasterclass

struct LikeButton: View {
    @State private var likes = 0

    var body: some View {
        Button("Like", systemImage: "heart.fill") { likes += 1 }
            .buttonStyle(.borderedProminent)
            .changeEffect(.jump(), value: likes)
            .particleBurst(.hearts, trigger: likes)
    }
}
```

コードを書く前にすべてのエフェクトを見るには、`#Preview` に `AnimationShowcase()` を置いてください。

## インストール

### Swift Package Manager

Xcode で **File › Add Package Dependencies…** を選び、リポジトリの URL を入力します。

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

または `Package.swift` の `dependencies` に追加します。

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git", from: "2.0.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIAnimationMasterclass", package: "SwiftUI-Animation-Masterclass")
    ])
]
```

2.0.0 以降を使用してください。1.0.0 リリースはビルドできませんでした。

## 使い方

以下のサンプルはすべて [`ReadmeSamples.swift`](Examples/MotionGallery/MotionGallery/ReadmeSamples.swift) からコピーしたもので、このファイルはサンプルアプリとテストターゲットでコンパイルされます。

### 値をバウンドさせながら落とす

`.gravityBounce()` は `Animation` です。値は新しい目標位置に落ち、そこでバウンドします。

```swift
struct DropBadge: View {
    @State private var isDropped = false

    var body: some View {
        Image(systemName: "bell.fill")
            .font(.largeTitle)
            .offset(y: isDropped ? 0 : -120)
            .animation(.gravityBounce(restitution: 0.5), value: isDropped)
            .onAppear { isDropped = true }
    }
}
```

### パーティクルでお祝いする

`.particleBurst(_:trigger:)` は値が変わるたびにバーストを放ちます。`.particleEffect(_:)` は view の上でエフェクトを出し続けます。

```swift
struct OrderButton: View {
    @State private var orders = 0

    var body: some View {
        Button("Place order") { orders += 1 }
            .buttonStyle(.borderedProminent)
            .particleBurst(.confetti, trigger: orders)
    }
}

struct WinterScene: View {
    var body: some View {
        LinearGradient(colors: [.indigo, .blue], startPoint: .top, endPoint: .bottom)
            .particleEffect(.snow)
            .ignoresSafeArea()
    }
}
```

### 変化に注目を集める

```swift
struct PasswordField: View {
    @State private var password = ""
    @State private var failures = 0

    var body: some View {
        SecureField("Password", text: $password)
            .textFieldStyle(.roundedBorder)
            .changeEffect(.shake(), value: failures)
            .onSubmit { if password.count < 8 { failures += 1 } }
    }
}
```

### view を表示・非表示にする

トランジションは、標準のものと同じように `if` と `withAnimation` で使えます。

```swift
struct PhotoReveal: View {
    @State private var showsPhoto = false

    var body: some View {
        VStack {
            Button(showsPhoto ? "Hide" : "Reveal") {
                withAnimation(.smooth(duration: 0.6)) { showsPhoto.toggle() }
            }
            if showsPhoto {
                Image(systemName: "photo.artframe")
                    .font(.system(size: 120))
                    .foregroundStyle(.blue)
                    .transition(.iris(origin: .topTrailing))
            }
        }
        .frame(height: 220, alignment: .top)
    }
}
```

### 勢いを保ったままドラッグする

2 つのデテント（停止位置）を持つ引き上げパネルです。ゆっくり離すと最も近い位置に戻り、フリックすると次の位置へ進みます。

```swift
struct PullUpPanel: View {
    @State private var detent = 1

    var body: some View {
        RoundedRectangle(cornerRadius: 24)
            .fill(.blue.gradient)
            .frame(height: 400)
            .overlay(alignment: .top) {
                Capsule().fill(.white.opacity(0.6)).frame(width: 40, height: 5).padding(10)
            }
            .snapDrag(.vertical, offsets: [0, 260], selection: $detent)
    }
}
```

### 独自のパーティクルエフェクトを作る

エミッターの各パラメータにはデフォルト値があるので、エフェクトを特徴づけたい部分だけを設定します。

```swift
let stardust = ParticleEmitter(
    source: .edge(.bottom),
    birthRate: 30,
    lifetime: 2...3,
    speed: 60...120,
    direction: .degrees(-90),
    spread: .degrees(20),
    size: 6...10,
    endScale: 0.3,
    forces: [.vortex(center: .center, strength: 80), .gravity(-20)],
    colors: [.white, .cyan],
    shapes: [.star],
    fadeIn: 0.1,
    blending: .additive
)
```

## アーキテクチャ

- `Sources/SwiftUIAnimationMasterclass/` には領域ごとに 1 つのフォルダがあります：`Physics`、`Gestures`、`Particles`、`Effects`、`Transitions`、`Scroll`、`Showcase`。
- モーションは view のコードを持たない値型で計算します：`DampedSpring`、`Decay`、`GravityBounce`、`RubberBand`、`SnapPoints`、`ParticleSystem`、`ChangeEffect.state(at:)`。modifier は environment を読み、ジェスチャやアニメーションの状態を保持して結果を適用するだけなので、計算部分は画面なしでユニットテストできます。
- `ParticleSystem` は SplitMix64 ジェネレータを使う struct で、シードがあらゆるプラットフォームでパーティクルを完全に決定します。`ParticleView` は `TimelineView` の中でこれを進め、すべてのパーティクルを 1 つの `Canvas` に描画します。生きているパーティクルがなくなると、クロックは停止します。
- パッケージ外から渡される値（実行時に変更されるエミッターの設定、フレーム時間、canvas のサイズ、ジェスチャの速度）はクランプされます。有限でない数値はシミュレーションに届かず、パーティクル数とバウンド回数には厳密な上限があります。
- CI は macOS で `swift test`、iPhone シミュレータで `xcodebuild test` を実行し、サンプルアプリを iOS と macOS 向けにビルドして、DocC ドキュメントを公開します。

テストをローカルで実行するには：

```sh
swift test                                    # macOS
xcodebuild test -scheme SwiftUIAnimationMasterclass \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```

## ロードマップ

- パッケージを Swift Package Index に追加する（`.spi.yml` はすでにリポジトリにあります）。
- パスに沿って動くアニメーション（タイミングカーブに従って view を `Path` に沿って動かす）。
- 同じ `Transition` プロトコルに基づくトランジションの追加（ページめくりなど）。
