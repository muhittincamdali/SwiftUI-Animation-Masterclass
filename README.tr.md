iOS 17+ ve macOS 14+ üzerinde SwiftUI için bir Swift hareket paketi: fizik tabanlı yaylar,
sürtünmeyle yavaşlama (decay) ve zıplamalar, parmağın hızını koruyan sürüklemeler, parçacık
efektleri, değişim efektleri ve geçişler. Bir framework'ü projesine dahil etmeden tek bir
ekranda bir efekt kullanmak isteyen uygulama geliştiricilere yöneliktir: her şey bir view
modifier, bir `Animation`, bir `Transition` ya da sade bir değer tipidir ve paketin hiçbir
bağımlılığı yoktur.

## Öne çıkanlar

- **Doğrudan çağırabileceğiniz fizik** — `DampedSpring` yay denklemini kapalı formda çözer
  (testler sonucu sayısal integrasyonla karşılaştırır), `Decay` bir fırlatmanın nerede
  duracağını öngörür, `GravityBounce` bir değeri düşürüp zıplatır, `.gravityBounce()` ise bunu
  bir SwiftUI animasyonu olarak çalıştırır.
- **Momentumunu koruyan sürüklemeler** — `.elasticDrag()` ve `.snapDrag(_:offsets:selection:)`
  bırakma hızını yaya aktarır, uçların ötesinde lastik gibi direnç gösterir ve hızlı bir
  fırlatmanın bir sonraki duruş konumuna kadar ilerlemesine izin verir.
- **Tek bir Canvas'ta parçacıklar** — 8 hazır ayar, 5 kuvvet ve 7 şekil (SF Symbols ve emoji
  dahil) tek bir `Canvas` ile çizilir; tohumlu (seeded) simülasyon aynı tohum için aynı
  kareleri üretir ve hiçbir zaman 10.000'den fazla parçacık tutmaz.
- **Değişim efektleri ve geçişler** — bir değer değiştiğinde oynayan shake, jump, spin, pulse,
  ping ve shine efektleri ile iOS 17 `Transition` protokolü üzerinde iris, wipe, flip ve pop
  geçişleri.
- **Hareketi Azalt ayarına uyum** — ayar açıkken parçacıklar çizilmez, değişim efektleri oynamaz,
  geçişler solarak gerçekleşir ve sürüklemeler kısa bir ease-out ile durur.
- **Testli, Swift 6** — macOS'ta 70 Swift Testing testi, bunların 66'sı bir iPhone
  simülatöründe de çalışır; NaN, sonsuz ve aralık dışı girdiler testlere dahil. Paket Swift 6
  dil modunda derlenir.

### Pakette neler var

| Alan | API |
| --- | --- |
| Fizik | `DampedSpring` (`gentle`, `snappy`, `bouncy`, `smooth`), `Decay`, `GravityBounce`, `.gravityBounce(fallDuration:restitution:)`, `RubberBand`, `SnapPoints` |
| Hareketler | `.elasticDrag(axes:resistance:spring:)`, `.snapDrag(_:offsets:selection:decay:spring:)` |
| Parçacıklar | `.particleBurst(_:trigger:)`, `.particleEffect(_:isActive:)`, `ParticleView`, `ParticleEmitter`, `ParticleForce`, `ParticleSystem` |
| Hazır ayarlar | `confetti`, `fireworks`, `snow`, `rain`, `sparkles`, `bubbles`, `hearts`, `embers` |
| Değişim efektleri | `.changeEffect(_:value:)` ile `.shake`, `.jump`, `.spin`, `.pulse`, `.ping`, `.shine` |
| Geçişler | `.iris(origin:)`, `.wipe(from:)`, `.flip(axis:)`, `.pop` |
| Kaydırma | `.scrollDriven(multiplier:)` (paralaks) |
| Demo | `AnimationShowcase`, her türden bir efekt içeren bir ekran |

## Hızlı başlangıç

**1. Paketi ekleyin**

Xcode'da **File › Add Package Dependencies…** menüsünü seçin ve depo adresini girin:

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

Bunu pencerenin sağ üstündeki arama alanına yapıştırın. **Dependency Rule** ayarını
`2.0.0` sürümünden itibaren **Up to Next Major Version** olarak bırakın ve **Add Package**'a
tıklayın. Açılan pencerede **SwiftUIAnimationMasterclass** yanındaki listeden uygulama
hedefinizi seçip **Add Package**'a bir kez daha tıklayın.

**2. Modülü içe aktarın**

```swift
import SwiftUIAnimationMasterclass
```

**3. Kullanın**

Herhangi bir view'a bir modifier ekleyin. Bu beğeni düğmesi her dokunuşta zıplar ve bir kalp
yağmuru fırlatır:

```swift
import SwiftUI
import SwiftUIAnimationMasterclass

struct LikeButton: View {
    @State private var likes = 0

    var body: some View {
        Button("Like", systemImage: "heart.fill") { likes += 1 }
            .buttonStyle(.borderedProminent)
            .changeEffect(.jump(), value: likes)
            .particleBurst(.hearts, trigger: likes)
    }
}
```

Kod yazmadan önce tüm efektleri görmek için `AnimationShowcase()` görünümünü bir `#Preview`
içine koyun.

## Kurulum

### Swift Package Manager

Xcode'da **File › Add Package Dependencies…** menüsünü seçin ve depo adresini girin:

```text
https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git
```

Ya da `Package.swift` dosyanızdaki `dependencies` listesine ekleyin:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-Animation-Masterclass.git", from: "2.0.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIAnimationMasterclass", package: "SwiftUI-Animation-Masterclass")
    ])
]
```

2.0.0 veya daha yenisini kullanın: 1.0.0 sürümü derlenmiyordu.

## Kullanım

Aşağıdaki her örnek, örnek uygulamanın ve test hedefinin derlediği
[`ReadmeSamples.swift`](Examples/MotionGallery/MotionGallery/ReadmeSamples.swift)
dosyasından kopyalanmıştır.

### Bir değeri zıplatarak düşürün

`.gravityBounce()` bir `Animation`'dır: değer yeni hedefine düşer ve orada zıplar.

```swift
struct DropBadge: View {
    @State private var isDropped = false

    var body: some View {
        Image(systemName: "bell.fill")
            .font(.largeTitle)
            .offset(y: isDropped ? 0 : -120)
            .animation(.gravityBounce(restitution: 0.5), value: isDropped)
            .onAppear { isDropped = true }
    }
}
```

### Parçacıklarla kutlayın

`.particleBurst(_:trigger:)` bir değer her değiştiğinde bir patlama üretir;
`.particleEffect(_:)` ise bir view'ın üzerinde bir efekti sürekli çalıştırır.

```swift
struct OrderButton: View {
    @State private var orders = 0

    var body: some View {
        Button("Place order") { orders += 1 }
            .buttonStyle(.borderedProminent)
            .particleBurst(.confetti, trigger: orders)
    }
}

struct WinterScene: View {
    var body: some View {
        LinearGradient(colors: [.indigo, .blue], startPoint: .top, endPoint: .bottom)
            .particleEffect(.snow)
            .ignoresSafeArea()
    }
}
```

### Bir değişikliğe dikkat çekin

```swift
struct PasswordField: View {
    @State private var password = ""
    @State private var failures = 0

    var body: some View {
        SecureField("Password", text: $password)
            .textFieldStyle(.roundedBorder)
            .changeEffect(.shake(), value: failures)
            .onSubmit { if password.count < 8 { failures += 1 } }
    }
}
```

### View'ları gösterin ve gizleyin

Geçişler, yerleşik olanlar gibi `if` ve `withAnimation` ile çalışır.

```swift
struct PhotoReveal: View {
    @State private var showsPhoto = false

    var body: some View {
        VStack {
            Button(showsPhoto ? "Hide" : "Reveal") {
                withAnimation(.smooth(duration: 0.6)) { showsPhoto.toggle() }
            }
            if showsPhoto {
                Image(systemName: "photo.artframe")
                    .font(.system(size: 120))
                    .foregroundStyle(.blue)
                    .transition(.iris(origin: .topTrailing))
            }
        }
        .frame(height: 220, alignment: .top)
    }
}
```

### Momentumla sürükleyin

İki durak noktalı (detent) yukarı çekilen bir panel: yavaş bırakma en yakın durağa döner,
hızlı fırlatma bir sonrakine geçer.

```swift
struct PullUpPanel: View {
    @State private var detent = 1

    var body: some View {
        RoundedRectangle(cornerRadius: 24)
            .fill(.blue.gradient)
            .frame(height: 400)
            .overlay(alignment: .top) {
                Capsule().fill(.white.opacity(0.6)).frame(width: 40, height: 5).padding(10)
            }
            .snapDrag(.vertical, offsets: [0, 260], selection: $detent)
    }
}
```

### Kendi parçacık efektinizi tasarlayın

Emitter'ın her parametresinin bir varsayılanı vardır; yalnızca efekti farklı kılan değerleri
ayarlayın:

```swift
let stardust = ParticleEmitter(
    source: .edge(.bottom),
    birthRate: 30,
    lifetime: 2...3,
    speed: 60...120,
    direction: .degrees(-90),
    spread: .degrees(20),
    size: 6...10,
    endScale: 0.3,
    forces: [.vortex(center: .center, strength: 80), .gravity(-20)],
    colors: [.white, .cyan],
    shapes: [.star],
    fadeIn: 0.1,
    blending: .additive
)
```

## Mimari

- `Sources/SwiftUIAnimationMasterclass/` altında her alan için bir klasör vardır: `Physics`,
  `Gestures`, `Particles`, `Effects`, `Transitions`, `Scroll` ve `Showcase`.
- Hareket, view kodu içermeyen değer tipleriyle hesaplanır: `DampedSpring`, `Decay`,
  `GravityBounce`, `RubberBand`, `SnapPoints`, `ParticleSystem` ve `ChangeEffect.state(at:)`.
  Modifier'lar yalnızca environment'ı okur, hareket veya animasyon durumunu tutar ve sonucu
  uygular; böylece matematik ekran olmadan unit test ile sınanır.
- `ParticleSystem`, SplitMix64 üreteci kullanan bir struct'tır: bir tohum, parçacıkları her
  platformda tamamen belirler. `ParticleView` onu bir `TimelineView` içinde ilerletir ve tüm
  parçacıkları tek bir `Canvas`'a çizer; hiçbir şey canlı değilken saat durur.
- Paketin dışından gelen değerler (çalışma anında değiştirilen emitter ayarları, kare süreleri,
  canvas boyutları, hareket hızları) sınırlandırılır: sonlu olmayan sayılar simülasyona
  ulaşmaz; parçacık ve zıplama sayılarının kesin üst sınırları vardır.
- CI, macOS'ta `swift test`, bir iPhone simülatöründe `xcodebuild test` çalıştırır, örnek
  uygulamayı iOS ve macOS için derler ve DocC dokümantasyonunu yayımlar.

Testleri yerel olarak çalıştırmak için:

```sh
swift test                                    # macOS
xcodebuild test -scheme SwiftUIAnimationMasterclass \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```

## Yol haritası

- Paketi Swift Package Index'e eklemek; `.spi.yml` depoda zaten var.
- Yol izleyen bir animasyon (bir view'ı zamanlama eğrisiyle bir `Path` boyunca hareket ettirmek).
- Aynı `Transition` protokolü üzerine kurulu daha fazla geçiş, örneğin sayfa kıvrılması.
